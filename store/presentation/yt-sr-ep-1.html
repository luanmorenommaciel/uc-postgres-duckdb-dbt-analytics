TEORIA · O FRAME ACADÊMICO
NÃO É OPINIÃO — É REVISÃO SISTEMÁTICA

O eixo onde a literatura de 2026 convergiu.

◆ INTENT 01
O quê
Intent
o quê deve ser feito — a especificação é a fonte da verdade.
  • Você declara o objetivo — a intenção vem antes do código.
  • A spec vira o contrato — ela dita o que é certo.
  • O código é derivado — não escrito à mão.
→ anel CONTEXT
◆ COLLABORATION 02
O como
Collaboration
como humano e IA trabalham juntos — orquestração, não digitação.
  • Humano dá julgamento — a decisão crítica é sua.
  • IA executa o loop — planeja, roda, corrige.
  • O harness define o ambiente — onde o agente vive.
→ anéis LOOP + HARNESS
◆ VERIFICATION 03
Está certo?
Verification
está certo? — evidência computada, não confiança em vibes.
  • Evals medem o resultado — qualidade vira número.
  • Testes fecham o loop — o agente prova que funciona.
  • Confiança tem receita — não vibe.
→ anel EVAL

O PAYOFF · A DEFINIÇÃO EM UMA FRASE

Engenharia Agêntica é construir o sistema em volta do modelo — contexto, ferramentas, gates e loops — pra que a IA entregue trabalho verificável sem você no meio.

O MODELO É O MIOLO — O SISTEMA É A DISCIPLINA
